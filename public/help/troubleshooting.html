# Troubleshooting Common Issues ## Login Issues ### "Invalid Credentials" Error **Solution:** 1. Check Caps Lock is off 2. Use "Forgot Password" 3. Clear browser cache 4. Try incognito mode ### "Account Locked" **Solution:** 1. Wait 30 minutes (auto-unlock) 2. Or reset password 3. Contact admin if urgent --- ## Dashboard Problems ### Dashboard Not Loading **Solution:** 1. Check internet connection 2. Press Ctrl + Shift + R (hard refresh) 3. Clear browser cache 4. Try different browser ### Metrics Not Updating **Solution:** 1. Press F5 to refresh 2. Check "Last updated" time 3. Wait 15 minutes for sync 4. Generate fresh report --- ## Command Center Issues ### Not Responding **Solution:** 1. Simplify your question 2. Rephrase clearly 3. Wait 1 minute and retry 4. Check if data exists ### Wrong Data **Solution:** 1. Verify with other reports 2. Check date range 3. Report error to tech support --- ## Voice AI Issues ### Calls Not Going Out **Checklist:** - [ ] AI enabled in settings? - [ ] Emergency stop NOT active? - [ ] Sufficient credits? - [ ] Phone numbers correct? ### Call Failed **Common Causes:** - Number not reachable - Call rejected - No answer - Customer busy --- ## Inventory Alert Problems ### Not Receiving Alerts **Solution:** 1. Check notification settings 2. Verify alert thresholds 3. Ensure alerts enabled 4. Check email/SMS settings --- ## Approval Queue Issues ### Empty Queue **Solution:** 1. Check "Pending" filter 2. Verify permissions 3. Clear browser cache 4.
