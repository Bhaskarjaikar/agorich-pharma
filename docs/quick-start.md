## Step 3: Try the Command Center (Most Important!)

The Command Center is your AI assistant. It's the fastest way to get answers.

### How to Open:
- Look for the chat box on the right side of Dashboard
- Or press `Ctrl + K` anywhere in the app

### Try These 5 Queries:

**1. "Hello"**
```
Type: Hello
Expected: AI greets you and offers help
```

**2. "Show my sales today"**
```
Type: Show my sales today
Expected: Today's sales summary with amount
```

**3. "Who owes me money?"**
```
Type: Who owes me money?
Expected: List of customers with overdue payments
```

**4. "What is low in stock?"**
```
Type: What is low in stock?
Expected: List of items below minimum stock
```

**5. "Any expiring items?"**
```
Type: Any expiring items this month?
Expected: List of items expiring soon
```

### Pro Tips:

| Tip | Benefit |
|-----|---------|
| Be specific | "Sales in Maharashtra" vs "Sales" |
| Add timeframes | "Last 7 days", "This month" |
| Ask follow-ups | "Show more" or "Why?" |
| Use natural language | AI understands Hindi and English |

## Step 4: Understand Your Role

Your access depends on your role:

### Admin/Super Admin
- Full access to all features
- Can access Emergency Controls
- Can approve/reject requests
- View all metrics and costs

### Distributor
- View own dashboard
- Manage own inventory
- Create invoices
- View own AR

### Retailer
- View products and pricing
- Create orders
- View order history
- Manage own profile

---

## Step 5: Key Features at a Glance

### 🔔 Notifications

Check the bell icon (top right) for:
- New alerts
- Approval requests
- System messages
- Payment updates

### 📦 Inventory Alerts

Go to **Inventory → Alerts** to see:
- Low stock items
- Expiry warnings
- Reorder suggestions

### 💰 Accounts Receivable

Go to **Finance → Receivables** to:
- See who owes you
- Track overdue payments
- View payment history

### ✅ Approvals

Go to **Notifications → Approval Queue** to:
- Review pending requests
- Approve or reject
- View approval history

---

## Step 6: Emergency Controls (Admins Only)

If something goes wrong, you can pause AI:

| Action | When to Use |
|--------|-------------|
| FULL_STOP | Complete shutdown needed |
| AGENT_PAUSE | Pause AI only (system keeps running) |
| APPROVAL_MODE | All actions need manual approval |

**Location:** Admin → Emergency Controls

## 🆘 Common Tasks Quick Reference

### Task: Check overdue payments
```
Go to: Dashboard → AR Overview
Or ask: "Show overdue payments"
```

### Task: Approve a discount request
```
Go to: Notifications → Approval Queue
Click: Approve or Reject
```

### Task: Add a new product
```
Go to: Inventory → Products → Add New
Fill: Product details and stock
```

### Task: Create an invoice
```
Go to: Sales → Create Invoice
Select: Customer and products
Save: Generate invoice number
```

### Task: View monthly report
```
Go to: Reports → Monthly
Select: Month and year
Download: PDF or Excel
```
